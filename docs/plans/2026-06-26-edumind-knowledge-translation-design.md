# EduMind 知识转译控制台设计

## 背景

老师给出的参考图强调的是“知识载体被 AI 转译成可交互学习界面”的视觉叙事。当前 `/edu-mind` 页面承载课程、资源、练习、思维导图等功能，但入口缺少清晰的第一屏故事，视觉上也更像多个模块拼接。

本次重构目标不是推翻现有功能，而是把 `/edu-mind` 的首屏改成一个“知识源 → 多智能体加工 → 个性化学习输出”的控制台，让用户和评审一眼看懂 EduMind 的价值。

## 设计目标

1. 首屏形成类似参考图的三段式叙事：左侧知识源，中间 AI 数据流，右侧学习工作台。
2. 保留现有课程、资源中心、练习中心、思维导图、学习记录、收藏夹、笔记等功能入口。
3. 降低现有页面的补丁感，统一深色玻璃、青蓝数据流、暖色知识点、绿色完成态等视觉语言。
4. 保持可用性优先：关键卡片必须能跳转到真实功能，而不是只做静态展示。
5. 第一版不做复杂拖拽或新后端能力，避免扩大风险。

## 页面结构

### 左侧导航

`src/components/edu-mind/Sidebar.vue` 继续负责 `/edu-mind` 内部导航，但做轻量视觉收束：

- 保留原有菜单项。
- 当前选中态更明确，减少大面积高饱和色。
- 底部学习进度继续保留，作为学生状态摘要。

### 主区域首屏

`src/components/edu-mind/HomeView.vue` 从空壳变为“知识转译控制台”。

首屏分三列：

- 知识源面板：展示当前课程、章节、知识点、教材、代码、题目等输入。
- AI 加工流：展示画像诊断、资源生成、路径规划、练习评估、反馈回写等节点。
- 学习工作台：展示今日推荐、下一步任务、资源卡、练习入口和学习状态。

首屏下方可补充轻量指标带：

- 本周学习时长。
- 推荐资源数量。
- 待完成练习数量。
- 画像更新状态。

### 现有功能承接

`src/views/EduMind.vue` 继续根据 `currentTab` 渲染各功能页：

- `课程` 仍进入 `CoursesView.vue`。
- `资源中心` 仍使用当前资源列表和生成面板。
- `练习中心` 仍进入 `PracticeView.vue`。
- `思维导图`、`学习记录`、`收藏夹`、`笔记` 保持现有组件。

首页卡片通过 `navigateToTab` 触发真实导航：

- 点击知识源或课程卡进入 `课程`。
- 点击资源生成流进入 `资源中心`。
- 点击今日练习进入 `练习中心`。
- 点击知识图谱进入 `思维导图`。

## 视觉方向

参考图中的“书 → 数据流 → AI 面板”会被转译为“课程知识库 → 多智能体加工流 → 学习工作台”。

视觉关键词：

- 深墨色背景，减少纯蓝紫大面积铺底。
- 青蓝色细线表达数据流和 AI 加工。
- 暖金色用于知识点、教材、章节等“知识源”元素。
- 绿色用于完成、已掌握、可开始状态。
- 玻璃面板用于工作台，但避免卡片套卡片。
- 按钮和入口使用真实图标，避免只靠文字解释功能。

## 交互行为

1. 首屏默认展示一个课程知识源和今日推荐任务。
2. AI 加工流节点可随时间或 hover 轻微高亮，表达系统正在处理。
3. 关键行动按钮直接切换 `currentTab`：
   - 开始课程。
   - 生成资源。
   - 今日练习。
   - 查看思维导图。
4. 保留移动端可用性：三列在窄屏下折叠为纵向模块，按钮不溢出。
5. 遵守 `prefers-reduced-motion`，动效可关闭。

## 组件边界

- `src/components/edu-mind/HomeView.vue`
  - 新增主要视觉和交互。
  - 接收 `weeklyHours`、`goalHours`。
  - 通过 `navigateToTab` 交给父组件切换功能页。
- `src/components/edu-mind/Sidebar.vue`
  - 只做视觉收束和必要的菜单体验优化。
  - 不改变事件协议。
- `src/views/EduMind.vue`
  - 保持页面编排和状态管理。
  - 如有需要，只做默认 tab、首页布局或样式作用域调整。

## 验证标准

1. `npm run build` 通过。
2. `/edu-mind` 首屏在桌面端能清楚表达三段式叙事。
3. 首页卡片能切换到对应真实功能页。
4. 文本在桌面和移动宽度下不溢出、不互相遮挡。
5. 现有课程、资源、练习、思维导图等入口仍可访问。
6. 不提交或覆盖无关工作区改动。
