# A3 赛题要求与实现映射表

| 赛题要求 | 当前实现位置 | 演示方式 | 可验证证据 | 风险与兜底 |
|----------|-------------|----------|-----------|-----------|
| 大模型能力 | 辅导智能体（TUTOR）调用大模型进行交互式讲解；资源生成智能体（RESOURCE）调用大模型生成个性化学习内容 | 现场输入学生问题，展示大模型实时生成针对性讲解和资源 | 大模型调用日志（含 prompt、response、耗时）；demo_trace_sample.json 中 tutor 和 resource 智能体的 output 字段 | 无 API Key 时使用 mock 数据降级演示，预设典型问答对保证流程完整 |
| 个性化资源生成 | 资源生成智能体（RESOURCE）根据画像薄弱点 + 学习偏好生成思维导图、例题拆解、代码练习 | 展示不同画像学生获得不同资源：偏好思维导图的学生获得可视化资源，偏好例题的学生获得代码拆解资源 | 资源生成日志（含输入画像、输出资源、适配偏好标签）；demo_trace_sample.json 中 resource 智能体的 evidenceTags | 大模型生成质量不稳定时使用预审模板库兜底，确保资源内容准确 |
| 多智能体协作 | 6 个智能体（画像、资源、路径、辅导、评估、反馈）按序协作，前序输出作为后序输入 | 展示完整工作流追踪：6 个智能体依次执行，输入输出衔接，25 秒完成闭环 | demo_trace_sample.json 完整工作流记录；各智能体 timestamp 证明执行顺序；前后智能体输入输出对应关系 | 单个智能体异常时跳过该环节并使用缓存数据，保证闭环不中断 |
| 学习画像 | 画像智能体（PROFILE）维护 24 维画像向量，实时更新掌握度和薄弱点 | 展示画像变化：辅导前指针 42%/图结构 38% → 辅导后 71%/65%，薄弱点从 3 项降至 1 项 | demo_trace_sample.json 中 profileSnapshot 与 profileAfterSnapshot 对比；画像维度变化记录 | 画像数据缺失时使用默认初始画像，确保流程可启动 |
| 效果评估 | 评估智能体（EVAL）对比辅导前后答题正确率，计算各维度掌握度变化和学习增益 | 展示评估报告：指针 +29%、图结构 +27%、整体 +23%，量化学习效果 | demo_trace_sample.json 中 eval 智能体输出；掌握度前后对比表；学习增益计算过程 | 评估数据不足时使用模拟答题数据进行演示，标注数据来源 |
| 可追溯证据链 | 每个智能体记录 input、process、output、confidence、evidenceTags、timestamp，形成完整证据链 | 展示 demo_trace_sample.json 全链路追踪，从画像分析到反馈建议每一步可查 | demo_trace_sample.json 各智能体完整字段；demo_trace_report.md 画像变化记录和路径调整记录；evidenceTags 标签体系 | 证据链断裂时通过 timestamp 和智能体 ID 进行关联补全 |
